01 / INGESTION

Multi-Format Parser & Chunker

Extracts raw text from PDF, DOCX, TXT, MD, HTML, CSV, and JSON (up to 100MB). Heuristically extracts department, dates, and policy IDs, slicing into 512-token hierarchical parent/child nodes.

AdaptiveChunker MetadataExtractor
02 / AGENTIC ROUTING

Query Router & Filter Inferer

Classifies intent into 5 types (factual, comparison, enumeration, procedural, conversational). Disambiguates terms (e.g. pronoun "it" vs IT Dept) and tunes retrieval parameters dynamically.

QueryRouter MetadataInferer
03 / DUAL RETRIEVAL

Hybrid RRF & Neural Rerank

Runs parallel ChromaDB dense search and BM25 sparse search merged via Reciprocal Rank Fusion (RRF). BGE Cross-Encoder reranks candidates on CUDA GPU with relative score threshold cutoffs.

ReciprocalRankFusion CrossEncoder
04 / GENERATION

Grounded LLM Synthesis

Injects expanded parent context and conversation history into Ollama LLM. Forces explicit [Source N] claim binding and mandatory abstention when evidence is insufficient.

Ollama LLM CitationEngine
05 / VERIFICATION

Self-Reflection & Retry Loop

Grades answer on Faithfulness (0.35), Completeness (0.30), Citation Coverage (0.20), and Coherence (0.15). If ungrounded claims appear, triggers an autonomous retry loop with adjusted retrieval dials.

SelfReflectionVerifier RetryEngine
01 / System Bootstrap

Where Everything Begins

Execution does not wait for the first user query to hit cold models. The application warms and pins all neural weights in VRAM on startup.

1

FastAPI Lifespan Trigger

backend/api/main.py initiates warmup_rag_system() on startup, initializing singleton dependency containers.

2

Dense Embedding Model Warmup

Loads BAAI/bge-small-en-v1.5 and runs a synthetic query embedding to warm GPU matrix caches.

3

Cross-Encoder Neural Reranker

Loads BAAI/bge-reranker-large onto CUDA GPU and executes a warmup inference pass on a test query-context pair.

4

Ollama LLM VRAM Pinning

Calls preload_model() with keep_alive=-1 to pin Qwen2.5 weights permanently in memory, ensuring sub-1s TTFT.

5

Vector Store & BM25 Verification

Verifies chunk counts across ChromaDB HNSW collection and in-memory BM25 index before accepting traffic.

02 / Execution Anatomy

The Complete Execution Path

Follow a single query from the moment it hits the SSE connection to the verified stream delivery.

01

HTTP Request & Session Lookup chat.py & chat_service.py

Client connects to POST /api/chat/stream. ChatService checks a thread-safe TTLCache (24-hour expiration) to pull previous multi-turn conversation history. Emits event: start with a unique response_id.

02

Query Classification & Strategy Routing query_router.py

QueryRouter classifies the query into one of 5 categories in under 1 millisecond using optimized regex heuristics:

Conversational Bypass: If classified as a greeting, the system completely bypasses vector retrieval and instantly yields a warm greeting response without wasted GPU cycles.
03

Semantic Cache Verification semantic_cache.py

Queries the semantic_cache ChromaDB collection. If cosine similarity ≥ 0.92 and KB version tags match, the cached answer and citations are streamed back smoothly via simulated SSE in sub-100ms.

04

Context-Aware Rewriting & Filter Inference query_rewrite.py & filter_extractor.py

Pronouns in follow-up queries (e.g. "What about it for managers?") are resolved into full standalone queries. QueryMetadataInferer extracts department filters while intelligently distinguishing the English pronoun "it" from "IT Department".

05

Hybrid Search (Dense + BM25) & RRF Fusion hybrid.py & vector_store.py

Executes parallel ChromaDB cosine retrieval and BM25 tokenized lexical retrieval. Ranked lists are combined using Reciprocal Rank Fusion: RRF = sum(1.0 / (60 + rank)).

Filter Relaxation Fallback: If an overly narrow department filter yields 0 candidate chunks, the system automatically drops the filter and re-executes search unfiltered to guarantee recall.
06

Neural Reranking & Context Expansion reranker.py & context_compression.py

BAAI/bge-reranker-large computes joint attention logits for (query, chunk) pairs. Chunks below top_score * min_ratio are pruned. Surrounding parent sections are retrieved from the docstore to preserve complete paragraph context. Emits event: retrieval.

07

Grounded Generation & Self-Reflection Verification pipeline.py & verifier.py & retry_engine.py

Ollama LLM generates an answer bound to bracketed [Source N] references. SelfReflectionVerifier evaluates the answer across 4 dimensions. If unverified claims exist, RetryEngine tightens retrieval dials and retries (up to 2 times).

08

SSE Streaming, Citation Mapping & Trace Telemetry chat_service.py & telemetry_service.py

Tokens are streamed live to the Next.js frontend via event: chunk. Verified citations emit via event: citation, and the complete audit trace emits via event: trace, completing the lifecycle with event: done.

04 / Component Anatomy

Core Architectural Components

A decoupled microservice architecture where each component possesses a single authoritative responsibility.

Central Nervous System

RAGPipeline (backend/rag/pipeline.py)

Coordinates the entire multi-stage retrieval, rewriting, reranking, generation, verification, and retry lifecycle. Manages thread-safe model switches across Ollama instances and coordinates async non-blocking semantic cache writes.

Inputs:user_query (str), filters (dict), history (list), model (str)
Outputs:RAGResponse (sync) / SSE Event Generator (stream)
Coordinates:HybridRetriever, CrossEncoder, Verifier, RetryEngine, SemanticCache
Agentic Layer

QueryRouter (backend/rag/query_router.py)

Classifies queries into 5 intent categories (factual, comparison, enumeration, procedural, conversational). Selects tuned retrieval hyperparameters (top_k, rerank_top_n, parent_expansion, temperature).

Latency:< 1.0 ms (Regex Heuristic)
Output:QueryClassification + RetrievalStrategy
Hallucination Guard

SelfReflectionVerifier (backend/rag/verifier.py)

Post-generation evaluator assessing answer quality across 4 weighted dimensions: 0.35 × Faithfulness + 0.30 × Completeness + 0.20 × Citation + 0.15 × Coherence. Detects ungrounded numerical claims and equipment categories.

Pass Gate:Composite ≥ 0.70 & Faith ≥ 0.65
Output:VerificationReport with critiques
Dual Retrieval

HybridRetriever (backend/retrieval/hybrid.py)

Fuses parallel ChromaDB dense vector queries and BM25 tokenized inverted index queries using Reciprocal Rank Fusion (RRF).

Formula:RRF(d) = ∑ 1/(60 + r)
Neural Precision

CrossEncoderReranker (backend/retrieval/reranker.py)

Joint cross-attention scoring using BAAI/bge-reranker-large on CUDA. Implements adaptive relative score cutoffs.

Device:Auto CUDA / RTX 4050
Autonomous Self-Healing

RetryEngine (backend/rag/retry_engine.py)

Dynamically broadens search parameters and tightens LLM prompt instructions when verification fails. Strictly capped at 2 retries.

Hard Cap:Max 2 Retries (3 Total Passes)
05 / The Specification Contract

The Tests Tell Us What the System Promises

Tests are not just quality checks; they are the executable behavioral contract of the entire architecture.

Strict Abstention When Info is Absent

test_generation.py

When retrieved document chunks are empty or irrelevant, the LLM is strictly prohibited from guessing or extrapolating facts.

Empty / Irrelevant Context → "I am unable to answer based on the provided documents."
"Zero hallucination tolerance in legal/HR compliance domains."

Deterministic Citation Binding

test_citations.py

Citations returned in the API payload must strictly match chunks that were explicitly cited in the answer text using [Source N] brackets.

Answer with [Source 1] → Returns Source 1 only (Uncited Source 2 & 3 pruned)
"Prevents ghost citations and unverified source attachments."

Atomic Code & Table Block Protection

test_chunking.py

Hierarchical chunking preserves fenced markdown code blocks and ASCII/HTML tables as atomic units, preventing split syntax errors.

```python code (80 lines)``` → is_atomic=True, content_type="code"
"Preserves structural integrity for technical and policy tables."

Filter Relaxation Fallback

test_e2e_agentic_layer.py

If inferred metadata filters (e.g. dept="Finance") yield zero candidates, the system must automatically drop filters and retry unfiltered.

Filtered Hits == 0 → filter_relaxed=True → Re-run Unfiltered Search
"Eliminates false negative empty answers due to strict metadata tags."
06 / Reliability Under Stress

One Failure Story: The Verification & Healing Loop

How the system actively detects an ungrounded hallucination, intervenes before streaming to the user, and self-heals.

Scenario: Hallucinated Home Office Allowance

A user asks: "Can I get reimbursed $5,000 for home office furniture?" The LLM initially answers affirmatively, hallucinating a $5,000 furniture allowance not grounded in the employee handbook.

STEP 1 / DETECTION

Faithfulness Gate Tripped

_evaluate_faithfulness() scans the answer for numerical figures ($5,000) and detects absence in retrieved context. Faith score drops to 0.35 (Pass threshold is 0.65).

STEP 2 / CRITIQUE

Autonomous Diagnosis

VerificationReport flags passed=False with critique: "Unsupported reimbursement amount or unverified equipment category: '$5,000'."

STEP 3 / ADAPTATION

Parameter Tuning

RetryEngine tightens reranker cutoff (min_score_ratio + 0.10), lowers temperature (0.10 → 0.05), and injects explicit correction instructions.

STEP 4 / RECOVERY

Verified Synthesis

LLM re-generates correctly: "The provided policy documents outline standard computer equipment, but do not specify a furniture allowance [Source 1]." (Score: 0.93 - PASSED).

Zero Cold Start

All dense embedders, cross-encoder neural models, and Ollama LLM weights are loaded and pinned in VRAM at startup.

03
